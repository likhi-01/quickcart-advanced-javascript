# QuickCart – Advanced JavaScript Practical Assignment

## About the Project

QuickCart is an online shopping application project developed using modern JavaScript (ES6+). This project demonstrates important JavaScript concepts through practical examples, including objects, classes, inheritance, array methods, asynchronous programming, performance optimization, DOM events, and real-world order processing.

The main objective of this project is to understand how JavaScript concepts work and how they can be applied in real-world applications.

## Technologies Used

- CSS3

## Project Modules

### Part A – Objects, Prototypes and ES6 Classes

- Creating objects using constructor functions.
- Using prototypes and prototype methods.
- Implementing ES6 classes.
- Understanding inheritance using `extends` and `super`.
- Practicing arrow functions, template literals, destructuring, rest parameters, and spread operators.

### Part B – Array Methods and Shopping Cart

- Using `map()` to transform product data.
- Using `filter()` to find products based on conditions.
- Using `reduce()` to calculate shopping cart totals.
- Practicing methods such as `find()`, `findIndex()`, `some()`, `every()`, and `sort()`.

### Part C – Advanced JavaScript Concepts

This section contains additional JavaScript practice and examples to strengthen problem-solving skills and understanding of JavaScript concepts.

### Part D – Asynchronous JavaScript

- Understanding the JavaScript event loop.
- Working with callbacks.
- Creating and handling Promises.
- Using `async` and `await`.
- Handling errors using `try...catch`.
- Practicing Promise methods.

### Part E – Performance Optimization and DOM Events

A simple shopping interface demonstrating:

- Debouncing for product search.
- Throttling for scroll events.
- Memoization for reusing calculated results.
- Event bubbling and event delegation.
- Removing products from the shopping interface.
- Updating cart totals.
- Checkout with a discount calculation.

### Part F – QuickCart Integration

An integrated order-processing example demonstrating:

- Creating products using ES6 classes.
- Destructuring customer details.
- Using `map()`, `filter()`, and `reduce()`.
- Managing unique product IDs using `Set`.
- Managing inventory using `Map`.
- Protecting configuration using `Object.freeze()`.
- Converting order data into JSON.
- Processing order confirmation using `async` and `await`.

## How to Run the Project

### Prerequisites

- Install Node.js.
- Install Visual Studio Code.

### Run JavaScript Files

Open the project folder in VS Code and open the terminal.

Run the required JavaScript file using Node.js:

```bash
node part-a-objects-classes/products.js
```

Example:

```bash
node part-b-array-methods/shopping-cart.js
```

You can run the other JavaScript files in the same way by providing their file paths.

### Run the Shopping Interface

1. Open the `part-e-optimization-events` folder.
2. Open `index.html` in your browser.
3. Test product search, product removal, cart updates, and checkout.
